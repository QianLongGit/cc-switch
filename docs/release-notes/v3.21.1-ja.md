# CC Switch v3.21.1

> 「プロジェクトルーティング」ページの気になる問題を修正：3 秒ごとの自動更新のたびにリストの並びが入れ替わり、ある行が「さっきはここ、今はあそこ」と動いてしまう——プロジェクトが多いほど顕著でした。本バージョンでは並び順を完全に決定論的にし、同じ秒にアクティブなプロジェクト間はパスの辞書順で固定、行はもう動きません。

## 修正内容

### プロジェクトルーティングのリスト並び替え問題

「プロジェクトルーティング」ページは最終アクティブ時刻の降順でプロジェクトを並べます。アクティブ時刻は秒精度に正規化されるため、複数プロジェクトが同一秒にアクティブになることはよくあります（同じ日に使った、セッションファイルの mtime が同一秒など）。これまでのソートは同秒の場合の規則を持たず、同一秒グループ内の相対順序は内部の順序なしハッシュマップのランダムな走査順に委ねられていました。ページは 3 秒ごとに再スキャンするため、そのたびにグループ内がシャッフルされ、行が上下に動いて見えました。プロジェクトの多いマシンでは特に目立ちました。

修正：同一秒にアクティブなプロジェクトはパスの辞書順でタイブレークします。パスは一意なためソートは完全に決定論的になり、更新をまたいで位置は一定になります。アクティブ時刻が本当に変わった場合は期待どおりプロジェクトが移動します。Claude アプリの「プロジェクトルーティング」ページのみに影響し、データベース移行はなく、その他の挙動は一切変わりません。
