# CC Switch v3.21.1

> 修复「项目路由」页面的一个易扰问题：列表每 3 秒自动刷新时，排序会发生跳变——某一行「一会在这里、一会在那里」，项目越多越明显。本版让排序完全确定：同一时刻活跃的项目之间按路径字典序固定排列，列表位置不再跳动。

## 修复内容

### 项目路由列表排序跳变

「项目路由」页按最近活跃时间降序排列项目。活跃时间归一到秒级精度后，多个项目同秒活跃十分常见（同一天先后用过、会话文件 mtime 同秒等）；而排序此前没有处理"同秒"的情况，同秒项目之间的相对顺序退化为内部无序哈希表的随机顺序——页面每 3 秒轮询重新扫描一次，同秒组内就洗一次牌，表现为某几行不断上下跳动，项目多的机器上尤其碍眼。

修复：同秒活跃的项目按项目路径字典序兜底排序。路径唯一，排序因此完全确定，跨刷新位置恒定；活跃时间真实变化时项目仍会正常移动（这是期望行为）。仅影响 Claude 应用的「项目路由」页，无数据库迁移，其余行为无任何变化。
