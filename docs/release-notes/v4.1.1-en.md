# CC Switch v4.1.1

This is a bugfix release: it fixes the SSH Hosts entry missing from the settings sidebar. When SSH remote session management shipped in v4.1.0, the SSH Hosts settings entry did not appear in the settings sidebar and was only reachable from the tray menu; this version restores the sidebar entry and adds a consistency check between the sidebar and navigation configuration to keep this class of missing-entry regressions from recurring. For the full v4.1.0 changelog, see the [v4.1.0 release notes](https://github.com/farion1231/cc-switch/blob/main/docs/release-notes/v4.1.0-en.md).

**Release date**: 2026-11-08

---

## Fixed

- **SSH Hosts entry missing from the settings sidebar**: in v4.1.0 the feature was only reachable from the tray menu; this version restores the sidebar entry and adds a consistency check between the sidebar and navigation configuration.
