# CC Switch v4.1.1

本版本是一个问题修复版本：修复设置页侧栏未显示「SSH 主机」入口的问题。v4.1.0 引入 SSH 远程会话管理时，「SSH 主机」设置入口未出现在设置页侧栏，只能从托盘菜单进入；本版本恢复侧栏入口，并新增侧栏与导航配置的一致性校验，防止同类入口缺失问题再次发生。v4.1.0 完整的更新内容请见 [v4.1.0 发布说明](https://github.com/farion1231/cc-switch/blob/main/docs/release-notes/v4.1.0-zh.md)。

**发布日期**：2026-11-08

---

## 修复

- **设置页侧栏未显示「SSH 主机」入口**：v4.1.0 中该功能需从托盘菜单进入；本版本恢复侧栏入口，并新增侧栏与导航配置的一致性校验。
