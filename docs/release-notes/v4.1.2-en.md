# CC Switch v4.1.2

This is a bugfix release: fixes an issue where the SSH connection multiplexing (ControlMaster) socket path could exceed the macOS 104-byte Unix domain socket limit when the app config directory is set to a deep path. In that scenario, remote session connections failed with "SSH connection or authentication failed". This version stores the socket in a short system temp path and automatically falls back to direct connections when the path is too long or contains spaces, keeping remote sessions always available.

**Release Date**: 2026-11-08

---

## Fixes

- **SSH ControlMaster socket path exceeded the macOS limit**: when the app config directory was set to a deep path, the ControlMaster socket path could exceed the macOS 104-byte Unix domain socket limit, causing remote session connections to fail with "SSH connection or authentication failed". Now uses a short system temp path (`/tmp/cc-switch-ssh-<user>`, mode 700) and falls back to direct connections when the path is too long or contains spaces.
