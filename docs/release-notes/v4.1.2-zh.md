# CC Switch v4.1.2

本版本是一个问题修复版本：修复 SSH 连接复用（ControlMaster）的 socket 路径在应用配置目录被设置到较深路径时超出 macOS Unix domain socket 104 字节限制的问题。此前该场景下远程会话连接会报「SSH 连接或认证失败」；本版本改用系统短路径存放 socket，并在路径超限或含空格时自动降级为直连模式，保证远程会话始终可用。

**发布日期**：2026-11-08

---

## 修复

- **SSH 连接复用（ControlMaster）的 socket 路径超出 macOS 限制**：当应用配置目录被设置到较深路径时，ControlMaster socket 路径会超出 macOS Unix domain socket 104 字节限制，导致远程会话连接报「SSH 连接或认证失败」。现改用系统短路径（`/tmp/cc-switch-ssh-<用户名>`，权限 700），并在路径超限或含空格时自动降级为直连模式。
