# CC Switch v4.2.0

This release is the second iteration of SSH remote host support: remote sessions now support **full-text content search** and a **copyable resume command**, the usage dashboard gains a **remote host dimension**, and the SSH host settings form is restyled to match app conventions.

**Release date**: 2026-11-08

---

## New

- **Content search for SSH remote sessions**: with a remote host selected in session management, the search box no longer stops at titles/summaries — full-text search runs via remote `rg` (ripgrep, auto-falling back to `grep` when unavailable) batch scanning, returning snippets with keyword highlighting for matching sessions; click to jump into the reader. No index is built for remote content; search terms are safely escaped before execution.
- **Copyable resume command for remote sessions**: the session list and reader now offer "Copy resume command" for remote sessions — one click copies the full `ssh -t user@host "cd <project-dir> && claude --resume <session-id>"` command; paste it in a terminal on the server to resume (Claude / Codex supported).
- **Usage stats for SSH remote hosts**: the usage dashboard gains a host switcher (same control as the sessions page). Remote usage uses an incremental mirror architecture: opening the page runs a lightweight manifest diff automatically (zero or minimal traffic); changed session files are fetched by byte-range increments and parsed locally, aggregated with the same semantics as local stats. First sync requires manual confirmation (with a file-count/size preview), is cancelable at any time, and covers the last 90 days by default. The daily rollup table gains a host dimension (v26→v27 migration, applied automatically); remote and local usage are strictly separated.
- **SSH host settings form polish**: content padding, field column ratios (narrow port column), footer buttons, and import-list density in the add/edit host dialogs now follow the app's established form conventions.

## Fixed

- **Remote usage auto-ingests newly created session files**: light sync now fetches new remote session files automatically (capped at 20 files / 50MB per round; the rest waits for the next round or a manual sync) instead of stalling at the first-sync snapshot.
- **Remote Codex stats protected from double counting**: when a remote file is truncated or an archive's mtime changes and triggers a rescan, history rows already rolled up are not re-inserted — host stats no longer double.
- Quoting of identity-file paths containing spaces in the copyable resume command.
