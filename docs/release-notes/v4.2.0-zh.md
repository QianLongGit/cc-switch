# CC Switch v4.2.0

本版本是 SSH 远程主机能力的二期增强：远程会话支持**正文内容搜索**与**复制恢复命令**，用量统计页新增**远程主机维度**，SSH 主机设置表单样式全面对齐应用规范。

**发布日期**：2026-11-08

---

## 新增

- **SSH 主机会话的正文内容搜索**：在会话管理选中远程主机后，搜索框不再只搜标题/摘要——正文内容搜索通过远端 `rg`（ripgrep，不存在时自动降级 `grep`）批量扫描实现，命中会话直接给出内容摘录与关键词高亮，点击可跳转阅读器定位。无需为远程内容建索引，搜索词经安全转义后执行。
- **远程会话复制恢复命令**：远程会话列表与阅读器现提供「复制恢复命令」，一键复制 `ssh -t 用户@主机 "cd 项目目录 && claude --resume <会话ID>"` 形态的完整命令，到服务器终端粘贴即可恢复会话（Claude / Codex 均支持）。
- **用量统计支持 SSH 远程主机**：用量统计页新增主机切换（与本地/远程会话页同款）。远程用量采用增量镜像架构：打开页面自动做轻量清单比对（零/极小流量），变化的会话文件按字节增量拉取后本地解析入库，与本地统计同口径聚合；首次同步需手动确认（预告文件数与流量），可随时取消，默认同步近 90 天。数据库日汇总表新增主机维度（v26→v27 迁移，自动完成），远程与本地用量严格分账互不污染。

## 优化

- **SSH 主机设置表单样式**：添加/编辑主机对话框的内容边距、字段列宽比例（端口窄列）、底部按钮区与导入列表密度全面对齐应用既有表单规范，观感与其它设置页一致。

## 修复

- **远程新增会话文件的用量自动入库**：轻量同步现会自动拉取远端新增的会话文件（单轮限 20 个文件 / 50MB，超出部分待下轮或手动同步），统计不再停留在首次同步时点。
- **远程 Codex 会话统计防重复计算**：远端文件被截断或归档时间变化触发重扫时，已过滚动汇总窗口的历史明细不会重复入库，主机统计不会翻倍。
- 复制恢复命令中私钥路径含空格时的引号处理。
