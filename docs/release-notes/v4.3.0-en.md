# CC Switch v4.3.0

This release adds data management and interaction fixes for SSH remote hosts: a **reset entry for per-host usage data**, **cleanup on host deletion**, and a fix for the usage-page host dropdown being blocked by its hover tip.

**Release date**: 2026-11-08

---

## New

- **Reset host usage data**: with a remote host selected on the usage dashboard, the host menu now offers "Reset host data". Use it when a bad sync leaves the host in a dirty state (sync shows complete but no data): it transactionally deletes all local usage data for that host (detail rows, daily rollups, sync cursors, dedup ledger — local and other hosts untouched), then returns the page to the first-sync preview for a clean rebuild. The entry is disabled while a sync is running to avoid clearing concurrent writes.
- **Cleanup on SSH host deletion**: deleting an SSH host in settings now also removes its local usage data and session caches (parse caches, scan manifest, transcript cache). Previously these lingered (the old copy said "caches are kept" — now updated to match). Cleanup is best-effort: if it fails, the host is still deleted with a warning.

## Fixed

- **Usage-page host dropdown blocked by hover tip**: while the host list is open, the trigger's hover tooltip no longer renders (it previously floated over the menu items, making them unclickable). The tooltip still shows when the dropdown is closed.
