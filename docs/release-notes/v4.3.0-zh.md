# CC Switch v4.3.0

本版本为 SSH 远程主机能力补充数据管理与交互修复：新增**重置主机用量数据**与**删除主机连带清理**，并修复用量页主机切换下拉被悬停提示遮挡的问题。

**发布日期**：2026-11-08

---

## 新增

- **重置主机用量数据**：用量统计页选中远程主机后，主机菜单新增「重置该主机数据」。用于同步异常留下脏状态（显示同步完成但无数据）时彻底重来——事务内清除该主机的全部本地用量数据（明细、日汇总、同步游标、去重记录，本机及其它主机数据不受影响），随后自动回到「首次同步」预告，一键重建。同步进行中该入口自动禁用，防止清表与写入并发。
- **删除 SSH 主机连带清理**：在设置中删除 SSH 主机时，现在会同时清除该主机的本地用量数据与历史会话缓存（解析缓存、会话清单、转录缓存）。此前这些数据会残留（旧版提示「缓存会保留」，现已按新行为更新文案）。清理为尽力而为：即使清理失败主机删除仍会完成，仅提示警告。

## 修复

- **用量页主机切换下拉被提示遮挡**：展开主机列表时，触发器上的悬停提示框不再渲染（此前会浮在菜单上方挡住列表项、导致无法点选）。关闭状态下悬停提示照常显示。
