# CC Switch v4.3.1

This release fixes a data-integrity defect in remote usage stats: when the same SSH host is deleted and re-added, its historical usage rows are silently swallowed by a cross-host dedup-key collision.

**Release date**: 2026-11-09

---

## Fixed

- **Include host dimension in the remote usage upsert key**: the remote ingestion dedup key (`request_id`) previously contained only the message ID — when the same remote host was deleted and re-added (getting a new host ID) and re-synced, rows for already-seen messages hit the primary key held by rows under the old host ID and were silently skipped, leaving the new host's usage empty with no warning. The remote key now embeds the host dimension (both the Claude and Codex pipelines); resetting and re-syncing the host after re-adding it restores the data in full. Local stats keep their existing key format and behavior unchanged.
