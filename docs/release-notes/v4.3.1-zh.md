# CC Switch v4.3.1

本版本修复一个远程用量统计的数据完整性缺陷：同一台 SSH 主机被删除后重新添加时，其历史用量数据会因跨主机去重键冲突而静默丢失。

**发布日期**：2026-11-09

---

## 修复

- **远程用量入库幂等键纳入主机维度**：此前远程会话用量的入库去重键（`request_id`）只含消息 ID、不含主机 ID——当同一台远端主机被删除后重新添加（主机 ID 随之更新）并重新同步时，相同消息的行会被旧主机名下的历史行占住主键而静默跳过，造成新主机名下数据缺失、用量统计显示为空且无任何提示。现远程入库键改为含主机维度的形态（Claude 与 Codex 两条链路均已修复），重新添加主机后重置并重新同步即可完整恢复数据。本机统计的键格式与行为完全不变。
